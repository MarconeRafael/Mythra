# Mythra

Persistent Narrative Engine for Interactive Story Generation

## Status

Early development.

## Overview

Mythra is an experimental narrative engine designed to explore
persistent story state, character memory, narrative planning,
consistency validation, and human-in-the-loop story generation.

## Goals

- Persistent narrative state
- Structured character models
- Character knowledge tracking
- Narrative planning
- Incremental chapter generation
- Consistency validation
- Human-controlled canonical state
- Evaluation and telemetry

## Planned stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- Docker
- pgvector
- pytest
- ML
